# Workflow Lab run evidence

`latest.json` is generated by `scripts/lab_smoke.py` against the live Cloudflare Worker.

The script creates a disposable ProofPack account, submits five source blocks—including a conflicting metric and an instruction hidden inside source text—checks the returned context map, deliverable, citations, and deterministic validator, then deletes the account.

Run it with:

```bash
python scripts/lab_smoke.py https://proofpack-kimi-arun.arunchandel1780.workers.dev
```
