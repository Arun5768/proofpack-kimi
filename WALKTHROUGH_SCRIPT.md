“This is ProofPack. I built it because application writing is usually not a writing problem—it is an evidence problem.”

“Our real work is scattered across repositories, event pages, articles, and personal notes. Generic AI tools see one prompt, so they can easily produce polished claims that are difficult to defend.”

“ProofPack starts with proof. For each application, a user saves the projects, events, links, metrics, and results that are actually relevant. Public links remain attached so important claims can be checked.”

## 0:36–0:49 — Move to the question and settings

“The user then pastes the exact application question, chooses a natural tone, and sets the real character limit. This sample asks why I would be useful as a Kimi Ambassador.”

“Kimi K2.5 reads the combined evidence and writes a focused answer. But the paragraph is only one part of the result. ProofPack also shows the facts Kimi used, its confidence, and anything the applicant should verify before submitting.”

## 1:09–1:22 — Point to “What would make this stronger”

“It also identifies the next proof that would make the answer stronger. Here, it recommends adding a public post or photo album confirming the event role.”
